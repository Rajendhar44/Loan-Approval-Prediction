# Loan Approval Prediction System

## Overview
This Machine Learning project predicts whether a loan application will be approved or rejected using Logistic Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Features
- Data preprocessing
- Missing value handling
- Label encoding
- Logistic Regression model
- Loan approval prediction
- Model saving using Joblib

## Accuracy
Achieved approximately 78% accuracy.

## Workflow
1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Model Training
5. Prediction
6. Model Saving
